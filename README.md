# CSSwithJs 🚀

A structured learning and practice repository focused on **CSS, JavaScript, DOM manipulation, Functions, Responsive Design, Grid, Flexbox, Tailwind CSS, and interactive web development**.

This repository documents my hands-on journey of learning and practicing modern front-end development concepts through dedicated lessons, experiments, and assignments.

---

## 📌 About This Repository

`CSSwithJs` is a practical front-end development repository where I am building my understanding of:

- 🎨 CSS fundamentals
- 📦 CSS Box Model
- 🧱 Display properties
- 📍 Positioning
- 🌊 Overflow
- 🔲 Flexbox
- 🗂️ CSS Grid
- 📱 Responsive Design & Media Queries
- 🔄 CSS Transform
- 🎛️ CSS Variables
- ✨ CSS Transitions
- 🎬 CSS Keyframe Animations
- ⚡ JavaScript Functions
- 🌐 DOM Manipulation
- 🖱️ JavaScript Events
- 🔥 Promises
- 🎨 Tailwind CSS
- 🧪 HTML/CSS/JavaScript Assignments

The main goal of this repository is **learning by building and experimenting with code**.
